# Manual Screenshot Assets

These PNG files are captures of the current Growth Monitor, desktop report
launcher, and browser labeling application. They are not redrawn interface
mock-ups. Every visible RHEED frame, sensor value, model curve, filename, and
annotation is generated by the capture harness. The harness does not connect
to instruments, ARM a session, load a model checkpoint, or read a laboratory
archive.

Regenerate the screenshots from the repository root in the `ai4mbe-gui`
environment:

```powershell
conda activate ai4mbe-gui
python -m tools.rheed_postprocessing_labeling.manual.capture_manual_screenshots `
  --output-dir tools/rheed_postprocessing_labeling/manual/assets/screenshots `
  --fixture-root D:\AI4MBE\scratch\manual-ui-fixture
```

The five committed outputs are:

- `chmbe_growth_monitor_dummy.png`
- `chmbe_growth_monitor_session.png`
- `rheed_labeler_build.png`
- `rheed_timeline_editor.png`
- `rheed_timeline_zoom.png`

The temporary ZIP, prediction CSV files, model specifications, generated
report, and browser state remain under `--fixture-root`, outside Git.
