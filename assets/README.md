# AI4MBE application icon

`ai4mbe_app_icon.png` is the high-resolution source used by the Qt GUIs.
`ai4mbe_app_icon.ico` contains 16, 24, 32, 48, 64, 128, and 256 px Windows
icon layers for desktop and Start-menu shortcuts.

The artwork is derived from the Yang Lab logo supplied for the GUI on
2026-08-17. The small-icon treatment retains the geometric M/Y mark and omits
the wordmark and heartbeat line so the symbol remains legible at taskbar size.
